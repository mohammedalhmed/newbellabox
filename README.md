# BellaBox Theme 2.0

ثيم BellaBox متوافق مع **Salla Twilight Theme Engine** لمتاجر الجمال والعناية. تمت إعادة بناء المشروع من نموذج أولي محدود إلى بنية متجر متكاملة تركز على سهولة الاكتشاف، وضوح تفاصيل المنتج، والتحويل على الجوال.

## ما تم استكماله

- نظام بصري موحد بخط Cairo، ألوان وردية/ترابية هادئة، حالات hover وfocus، واستجابة كاملة.
- رأس متجر فعلي مع شريط إعلان، تنقل سطح المكتب والجوال، بحث، حساب، وسلة.
- الصفحة الرئيسية مع مقدمة تحريرية، نقاط الثقة، مكوّنات Salla Home الديناميكية، ودعوة للمجلة.
- صفحة قوائم المنتجات مع الفلاتر، الفرز، التصفح اللانهائي، ومسارات التنقل.
- صفحة المنتج المفرد مع الصور المصغرة، السعر، الخصم، التقييم، الوسوم، الخيارات، الملاحظات، الكمية، الإضافة للسلة، التقييمات، والمنتجات المرتبطة.
- صفحة السلة مع تحديث الكمية، الحذف، الشحن المجاني، الكوبونات، وملخص الطلب.
- صفحات المجلة: قائمة المقالات، التصنيفات، المقال المفرد، الوسوم، الإعجاب والتعليقات.
- صفحات الماركات: قائمة الماركات وصفحة الماركة مع منتجاتها.
- الصفحات الرسمية الأخرى في Twilight: الحساب، الطلبات، تفاصيل الطلب، المفضلة، الإشعارات، المحفظة، الولاء، الشكر، الصفحة الثابتة، وصفحة الهبوط.
- إعدادات `twilight.json` للتحكم في الرأس، التذييل، الإشعارات، الشريط المثبت، ومسارات التنقل.
- hooks الرسمية وSalla Web Components للحفاظ على تكامل السلة، الدفع، الحساب، الفلاتر، التعليقات، البحث، والمكوّنات الديناميكية.

## التشغيل والتحقق

يتطلب المشروع Node.js وSalla CLI:

```bash
npm install
npm run dev      # salla theme dev
npm run build    # salla theme build
npm run publish  # بعد تسجيل الدخول وتجهيز الثيم في Partners Portal
```

أثناء التطوير على سلة يفضل استخدام:

```bash
salla theme preview
```

لأن المعاينة الرسمية توفر بيانات المتجر، المكوّنات، المنتجات، الحساب، والسلة كما تظهر في بيئة Twilight الحقيقية.

## ملاحظات تكامل مهمة

- أسماء ومسارات صفحات Twilight الرسمية لا ينبغي تغييرها؛ لذلك تم إنشاء الصفحات في مساراتها المعتمدة داخل `src/views/pages`.
- المنتجات والصور والمقالات لا تحتوي على بيانات وهمية داخل الثيم؛ يتم عرضها من كائنات Salla ومكوّناتها الرسمية.
- أي صفحة ثابتة مثل سياسة الشحن أو الخصوصية يمكن إدارتها من لوحة سلة وتظهر عبر `page-single.twig`.
- لا يلزم تعديل `main.js` عند إضافة منتجات أو أقسام؛ المكونات الرسمية تتولى البيانات، بينما يتولى الثيم العرض والتفاعل العام.

## التحقق المنفذ

تم التحقق من صحة ملفات JSON وJavaScript، ومراجعة مراجع القوالب والجزئيات، والتأكد من وجود جميع مسارات الصفحات الرئيسية والحساب والمتجر. يتبقى اختبار المعاينة المرئية داخل متجر Demo في Salla Partners للتأكد من بيانات المتجر الفعلية وتوافق Web Components مع إصدار الحساب.
